# Career Roadmap for Tamegai

This repository is a personal career planning tracker designed for long-term freelance and remote software development work.

## 🌟 Goal
Work on projects I enjoy, on my own schedule, and earn a reliable income through overseas remote contracts.

## 💂 Strategy
Use GitHub Issues + Projects v2 to break down the career plan into manageable tickets with a parent-child structure.

---

## 🧰 Task Structure (suggested issues)

### 🪜 Epic: Career Plan Setup
- [ ] Create this GitHub repo and README (you are here!)
- [ ] Set up GitHub Project board (v2)
- [ ] Define goal in the README

### 🔗 Epic: Public Portfolio Creation
- [ ] Create a demo project repo simulating actual work experience
  - [ ] Add `README.md` in English
  - [ ] Add representative code (Zephyr + MQTT sample, etc.)
- [ ] Publish an article in Qiita or Zenn (EN/JP)
- [ ] Link portfolio to GitHub profile

### 🔐 Epic: Professional Presence
- [ ] Create LinkedIn profile in English
- [ ] Join Malt, Toptal or Upwork
- [ ] Add bio and skills
- [ ] Start browsing remote jobs with keyword "Switzerland"

### ✅ Epic: First Contract Acquisition
- [ ] Submit first proposal
- [ ] Conduct online interview / chat
- [ ] Sign agreement (freelance/contract base)

### 🚀 Epic: Income Stability Phase
- [ ] Achieve monthly contract of ¥5-10万円
- [ ] Move toward recurring monthly contracts (¥20万円目標)
- [ ] Consider LLC registration via freee

### 🌿 Epic: Long-term Positioning
- [ ] Consider mentorship, tech articles, or advisor roles
- [ ] OSS contributions for visibility
- [ ] Revisit roadmap yearly
